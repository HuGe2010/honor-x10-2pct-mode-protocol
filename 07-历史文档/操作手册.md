## 阶段 1：连接手机 + 体检（不破坏任何东西）

手机端：设置 → 关于手机 → 连点「版本号」7 次开启开发者选项 → 开发者选项 → 打开 **USB 调试**。
用数据线（不是纯充电线）插到电脑，手机上弹出「允许 USB 调试」时点**允许**。

```powershell
cd C:\Users\<user>\Documents\deepseek-harness\default-workspace\honor-x10-root\platform-tools
.\adb.exe devices -l
.\adb.exe shell getprop ro.product.model          # 应为 TEL-AN00 / AN00a / AN10 / TN00
.\adb.exe shell getprop ro.build.display.id       # 当前系统版本（EMUI 10.1.x 或 鸿蒙 2/3）
.\adb.exe shell getprop ro.board.platform         # 芯片平台，确认是 kirin820
.\adb.exe shell getprop ro.build.version.release  # 安卓底层版本
```

检查是否**已经解锁**（有些二手机已经被解锁过）：

```powershell
.\adb.exe reboot bootloader
.\fastboot.exe oem get-bootinfo
# 输出 Bootloader Lock State: UNLOCKED  → 已解锁，可直接跳到阶段 4
# 输出 Bootloader Lock State: LOCKED    → 需要阶段 2、3
.\fastboot.exe reboot
```

**记录这三项，后面每一步都要用**：机型、当前系统版本、锁状态。

## 阶段 2：获取 16 位解锁码（唯一的"付费/拆机"环节）

华为 2018-07 关闭官方解锁码通道，荣耀 X10 是 2020 年机型，没有免费自助路径。
下面三条路选一条：

### 方案 2A：付费代读码（最省事，推荐）

- 渠道：淘宝 / 闲鱼 / 本地手机维修店 / B 站维修区，关键词「华为荣耀 解BL 解锁码」「代开BL」
- 市场报价：几十元级别（老机型低至 2 元，麒麟 810/820/980/985 这类偏高）
- 你要问清 5 件事：
  1. 荣耀 X10 / 麒麟 820 / 具体型号支持吗？
  2. 需要拆机短接，还是软件 testpoint（不拆机）？
  3. 给的是**永久解锁码**，还是只是临时打开"工厂锁"（重启会不会锁回去）？
  4. 解锁后 OTA、华为钱包、支付类 App 什么影响？能否回锁？
  5. 失败/变砖怎么处理，有没有保障？
- 交付物：**16 位数字解锁码**（也可能是 16 位字母数字混合）

### 方案 2B：自助（买工具授权 + 软件 testpoint，不拆机）—— ⚠️ 对麒麟 820 基本已排除

**已核实的事实（2026-10-03 抓取 hcu-client.com/supported-models.php，1188 行机型表）**：

- HCU / DC-Unlocker 官方支持机型表里的海思芯片**最高只到 HiSilicon KIRIN980**，
  完整列表：K3V2 / KIRIN620 / 650 / 655 / 658 / 659 / 710 / 710A / 710F / 910 / 910T / 920 / 925 / 930 / 935 / 950 / 955 / 960 / 970 / 980
- **没有 KIRIN820、没有 985、没有 990** → 用 HCU 读麒麟 820 的解锁码**不可行**
- 表头还明确写着两条警告：
  - 进出软件 testpoint 需要配合 **DC-Phoenix**
  - **Android 10.0 及以上的软件 testpoint 可能不工作**，此时必须用原厂文件或**拆机接硬件 testpoint**
  - 荣耀 X10 正好是 Android 10 → 双重不利
- 官方还有一句：*Credits lost for reading bootloader code on not supported models are not returned or refundable*
  （在不支持的机型上尝试读码，扣掉的点数不退）

**SigmaKey / Sigma Plus 的情况（存疑，别先花钱）**：

- 官方手册确实写了：*Software testpoint for devices on HiSilicon Kirin 710 / 65x / 95x / 810 / **820** / 960 / 970 / 980 / 985 / 990 / 990E / 990 5G*
- 但**「支持软件 testpoint（进工厂模式）」≠「支持读 bootloader code」**。
  该手册里"获取 bootloader 密码"的演示全部是老机型，**麒麟 820 读码没有明确列出**
- 且 Sigma 授权成本远高于 HCU（需 Box / Dongle 或在线授权）
- 结论：**除非卖家能书面确认「Kirin 820 + TEL-AN00 读 bootloader code 可用，失败退款」，否则不要为此先买授权**

**其它工具**：Ultimate NCK、Octoplus 一类同理，付款前必须先确认麒麟 820 支持。

**已逐一核实「不支持麒麟 820」的公开工具清单**：

| 工具 | 麒麟 820 | 依据（2026-10-03 核实） |
|---|---|---|
| **HCU / DC-Unlocker** | ❌ | 官方机型表 1188 行，海思芯片最高只到 KIRIN980；且表头警告 Android 10+ 软件 testpoint 可能失效 |
| **UnlockTool** | ❌ | 机型库中 HiSilicon 条目最高 Kirin 980；带 `[Unlock BL]` 标记的**只有 Kirin 710 / 710F（Emmc/Ufs）** |
| **PotatoNV** | ❌ | README 明确列出不兼容 710/710A/710F/810/970/980/985/990 及更新芯片 |
| **Huawei-Unlock-Tool**（免费开源、无狗） | ❌ | README 原文：支持 620/620(CAM)/65x_a/65x_b/710/810/925/935/950/955/960/970，「in theory 980」，且**必须 EMUI 8 或 EMUI 9**；荣耀 X10 出厂 EMUI 10.1，双重不符 |
| **UnlockedHuaweiBootloader**（配套解锁版 BL 镜像包） | ❌ | 镜像列表全是老机型代号（ALE/AGS/FIG/PE/PLK/GRA/DUK/FRD/EVA/STF…），无 820 / X10 / TEL- |
| **SigmaKey / Sigma Plus** | ⚠️ | 仅确认支持「软件 testpoint 进工厂模式」，**读 bootloader code 未确认** |

⚠️ **常见误判**：在 UnlockTool 机型库里搜「820」能搜到 21 条，但全部是**高通骁龙 820（MSM8996）**（LG V20、ZTE Axon 7、一加 3 等），与麒麟 820 毫无关系。

**为什么「代开 BL」能收费**：公开工具的瓶颈不在软件，而在**对应芯片的 loader + 解锁版 bootloader 镜像**。谁能拿到麒麟 820 的 loader 和已签名的解锁 bootloader，谁就能解锁——这是不公开的资源。所以那几十元买的是这个资源，不是软件。

### 方案 2C：硬件短接（拆机，风险最高）

- 拆后盖，短接主板 testpoint 进深刷口（HUAWEI USB COM 1.0），读码或写底层
- 社区报告麒麟 820 该方法**可行**；酷安有免费帮读的人
- 需要动手能力 + 对应机型的短接点位图

### ⚠️ 明确无效的路径

- 「输入 IMEI 算解锁码」的暴力枚举工具：**只对 2018 年前老机型有效**，安卓 9+/鸿蒙机型无效
- 号称「免解锁一键永久 root」的工具：华为 BL 锁是硬件级，不解锁不可能永久 root，这类工具基本是广告/病毒

## 阶段 3：解锁 Bootloader（**会清空全部数据**）

前置：手机电量 > 50%，已备份数据（照片/微信/账号），已拔出 SD 卡。

```powershell
cd C:\Users\<user>\Documents\deepseek-harness\default-workspace\honor-x10-root\platform-tools
.\adb.exe reboot bootloader
.\fastboot.exe devices                      # 确认能看到设备
.\fastboot.exe oem unlock 你的16位解锁码
# 若工具是用 COM1.0 写底层打开了"工厂锁"，则不带码：
# .\fastboot.exe oem unlock
.\fastboot.exe oem get-bootinfo             # 应显示 UNLOCKED
.\fastboot.exe reboot
```

解锁后手机首次开机很慢（会重新初始化数据分区），属正常。
**回锁**（如需送修）：`fastboot oem relock <解锁码>`，但部分机型回锁后无法再解。

## 阶段 4：刷 Magisk 获取 root

华为的坑：**Magisk 里「Ramdisk」显示"否"**，因为 ramdisk 不在 boot 分区，而在 `recovery_ramdisk`。

1. **取原厂固件里的 `recovery_ramdisk.img`**
   - 固件来源：与手机**当前版本完全一致**的官方 SD_update 包
   - 从 `update.app` 里解出 `RECOVERY_RAMDISK.img`（用 HuaweiUpdateExtractor 或 7z 解 update.app）
2. **手机端修补**
   - 安装 `Magisk-v30.7.apk`
   - Magisk → 「安装」→「选择并修补一个文件」→ 选 `recovery_ramdisk.img`
   - 产物：`magisk_patched-30700_xxxxx.img`（在手机 Download 目录）
3. **回传到电脑并刷入**
   ```powershell
   .\adb.exe pull /sdcard/Download/magisk_patched-30700_xxxxx.img .
   .\adb.exe reboot bootloader
   .\fastboot.exe flash recovery_ramdisk magisk_patched-30700_xxxxx.img
   .\fastboot.exe reboot
   ```
4. **激活 root**
   - 关机 → 按住 **音量上 + 电源** 进入 recovery
   - 在 recovery 里选择重启系统 → 开机后 Magisk 会提示「修复运行环境」→ 确定 → 再次重启
5. **保持 root 的方式**：以后每次冷启动都要**先经 recovery 再进系统**（华为特有）。

### ❌ 绝对不要做的事

**不要用 TWRP 去格式化 /data**。华为把大量系统组件放在 data 分区，格式化会直接变砖。
华为机型刷 Magisk 也**不要**用 TWRP 卡刷，用上面的修补 recovery_ramdisk 方式。

## 鸿蒙 → EMUI 官方回退探测结果（2026-10-03 实测，结论：通道已关闭）

用 HiSuite 11.0.0.610_OVE 连上 TEL-AN10，点「系统更新」触发查询。三层证据一致：

**① 网络请求层** —— HiSuite 向华为服务器发了三种包查询：

| 请求类型 | 含义 |
|---|---|
| `packageType: full` | 常规升级包 |
| `packageType: hfull_switch` | **切换到其他版本** |
| `packageType: full_back` | **回退包**（请求里固件名带 `_EmotionUI_10.1.1` 后缀） |

`full_back` 请求原文：
```
VendorCountry: all-cn    C_Version: C00    DeviceName: TEL-AN10
packageType: full_back
FirmWare_Base:    TEL-LGRP1-CHN 102.0.0.270_EmotionUI_10.1.1
FirmWare_Cust:    TEL-AN10-CUST 102.0.0.230(C00)_EmotionUI_10.1.1
FirmWare_Preload: TEL-AN10-PRELOAD 102.0.0.5(C00R7)_EmotionUI_10.1.1
```

**② 响应处理层** —— 日志：
```
reader parse format ok.  →  fn=2 RESULT: FALSE  CAUSE: invalid  →  invalid
Enter BL SystemFull.
BL SystemFull full have new version.   HotaVer is [103.0.0.165(C00E165R7P2)]
```
回退包响应被判定 **invalid**（无有效回退包），随后走常规升级路径，返回新版本。

**③ UI 层** —— 弹出的「系统更新」窗口内容：
```
HarmonyOS
发现新版本
3.0.0.165(C00E165R7P2)
更新详情：亲爱的用户，HarmonyOS 3 如期而至！……
[ 升级 ]
```
**只有"升级"按钮，没有"切换到其他版本"入口。**

### 结论

**华为对 TEL-AN10 的官方 EMUI 回退通道已经关闭。** 官方现在只提供升到鸿蒙 3.0，不提供退回 EMUI 10.1.1。

### ⚠️ 重要：不要点那个"升级"

升到鸿蒙 3.0 会抬高版本号、增加防回滚（anti-rollback）计数，后续想降级会更难。

4. 手机连上，Proxy 右侧显示 Phone Model / Region
5. 准备 EMUI 10.1.1.156 固件包（或经 Firm Finder 查找）
6. Firm Finder → `View Rom` → `Add Rom`
7. HiSuite → 设置 → 常规设置 → 代理设置 → `127.0.0.1:7777`
8. 系统更新 → 核对注入的 ROM → 执行

### 🎯 结论

**技术上可行、有同机型先例，但属于不可逆风险操作。**
最危险的一点是：降级可能弄坏 Fastboot/USB，而**我们没有解锁码**，一旦出问题只能送修。

### 🔬 防回滚预读结果（2026-10-03 实测）：**做不到**

进入 bootloader 后逐个探测，**锁定的 bootloader 拒绝几乎所有查询**：

| 命令 | 结果 |
|---|---|
| `oem get-product-model` | ✅ `TEL-AN10` |
| `oem get-build-number` | ✅ `:TEL-AN10 2.0.0.270(C00E230R7P5)` |
| `getvar max-download-size` | ✅ `471859200` |
| `getvar all` | ❌ `Command not allowed` |
| `getvar unlocked / secure / serialno / product / current-slot / version-bootloader` | ❌ 全部 `Command not allowed` |
| `getvar rollback-index` / `anti-rollback` / `arb` | ❌ `Command not allowed` |
| `oem device-info` / `read_bsn` / `get-rollback-index` / `get-anti-rollback` / `get-secure-boot-state` | ❌ `Command not allowed` |
| `oem backdoor info` | ❌ `Command not allowed` |

**重要推论**：
1. **防回滚状态无法预读** → 只能实际刷入时才知道会不会被拒
2. **fastboot 刷写通道完全关闭**（硬锁定状态）→ 除 `oem get-product-model` 一类只读命令外，`flash`/`erase` 必然被拒
   → 这意味着**唯一可用的刷写通道是官方签名的 Upgrade mode**（HiSuite / dload / eRecovery）

**系统属性里的线索**（不足以定论）：
```
ro.boot.vercnt1          = 1        ← AVB 版本计数器
ro.boot.vbmeta.device_state = locked
ro.boot.avb_version      = 1.1
ro.huawei.build.version.security_patch = 2022-07-01
```
`vercnt1=1` 是 AVB 防回滚计数器的线索，但**无法据此判断** EMUI 10.1.1 包的 rollback index 是否 ≤ 1。

### 🎯 修正后的结论

原本计划的"三项零成本验证"，**第 2 项（预读防回滚）已确认做不到**。剩下：

1. **打售后电话**（唯一零风险路径）
2. **确认 EMUI 10.1.1.156 (C00E150R5P1) 固件包能拿到**

**防回滚只能在实际刷入时才知道** → Proxy 路线的赌博成分比原先评估更高：
可能准备半天、清空了数据，却在刷入阶段被 bootloader 直接拒绝。

## HiSuite Proxy 路线 · 深入核实结果（2026-10-03 第二轮）

### 🎯 最有价值的证据：2024-11 同代机型完整成功教程

博客园《**荣耀9X鸿蒙降级刷EMUI9.1.1.205方法（20241125）**》（2024-11-25，阅读 1.6 万）
荣耀9X = 麒麟 810，与荣耀X10（麒麟 820）同代。作者完整跑通并留下细节：

**① 副作用不是必然的** —— 标题就写着：
> **（USB连电脑和快充都正常，可OTA升级）**

并给出关键经验：
> "降级到 EMUI9.1.1.168/126 后无法 USB 连电脑，后期可以通过手机自带的升级系统直接升级上来。
> 按照道理**在升级到 EMUI10.1.1.134（或138）及以上版本会恢复 USB 连接电脑的问题**。"

→ **只要目标版本 ≥ EMUI 10.1.1.134，USB/快充就正常**，我们本来要的就是 EMUI 10.1.1，正好在这个安全区间。

**② 工具版本（与我原先装的 11.0.0.610 不同！）**
- **HiSuite_10.1.0.550_OVE**（不是 11.0.0.610）
- **HiSuite Proxy V3.3.0**

**③ 关键前置开关**：手机 设置 → 搜索 **HDB** → 打开"**允许 HiSuite 通过 HDB 连接设备**"
→ 已核实本机：`settings get system hdb_enabled` = **1** ✅ 已开启

**④ 流程要点**
- HiSuite 设置 → 常规设置 → 代理设置 → `127.0.0.1:7777`
- Firm Finder：Phone Model `TEL-AN10`，Region `C00`，Vendor/Country `all-cn`，OS Target 填目标版本
- Add ROM（base + cust + preload 三个包）→ 回 Proxy 核对 packages name → 勾选 **force auth bridge** → SETUP
- 等出现 "xxx now!" → HiSuite 点检测更新 → 出现目标版本 → 升级
- **全程手机不能离开 HiSuite 界面**

### 固件包：确认可得

| 版本 | 说明 | 来源 |
|---|---|---|
| `TEL-AN10 10.1.1.156 (C00E150R5P1)_Firmware_EMUI10.1.1_05016LBJ.zip` | **4.73 GB** | vngsmservices.com / halabtech / onfix / rom100 / donghairom |
| `3.1.1.180 (C00E170R7P1)` | **Magic UI 3.1.1**（荣耀品牌的 EMUI 10.1.1），Android 10，Kirin 820 | donghairom / 66rom / cfroot / romzj |
| `高维禁用_Teller-AN00DW 10.1.1.191 (C00E185R7P1)` | **降级中转包**（"高维禁用"= 绕过版本校验） | romzj.com.cn |

**安全网**：华为固件由华为签名，bootloader 会校验签名 → 第三方网站即使重新打包，改过的包**刷不进去**，所以被植入恶意代码的风险很低。

### 修正后的结论

| 维度 | 原评估 | 修正后 |
|---|---|---|
| 固件可得性 | 未知 | ✅ 确认可得，多来源，多版本 |

**从"中高风险的赌博"上调为"有明确先例的可执行方案"。**

剩余不可消除的风险：**变砖后无自救手段**（未解锁，救砖需 COM1.0 工厂模式 + 原厂 board 固件 → 送修）。

## 🔴 root 可行性最终结论（2026-10-03）：**没有免拆机的方案**

用户主目标是 root。完整排查后结论明确：

> **root 的唯一前提是解锁 BL；而荣耀X10（麒麟820 + 鸿蒙2.0）解锁 BL 必须拆机短接。**

### 证据链（全部实测或权威来源核实）

| # | 来源 | 结论 |
|---|---|---|
| 1 | **《刷机指南》jesse205.github.io 华为解锁页** | 华为解锁方法"**只适用于老设备（EMUI 9 及以下）**"；"**新设备已经关闭了解锁命令，您可能需要拆机才可以解锁**" |
| 2 | HCU / DC-Unlocker 官方机型表 | 海思芯片最高 **Kirin 980**，无 820/985/990 |
| 3 | UnlockTool 机型库 | `[Unlock BL]` 仅 **Kirin 710 / 710F** |
| 4 | PotatoNV | 最高 **Kirin 960** |
| 5 | Huawei-Unlock-Tool（免费开源） | 最高 Kirin 980，硬性要求 **EMUI 8/9** |
| 6 | 淘宝商家（用户实测询问） | 明确回答：**要拆机短接** |
| 7 | 知乎华为 root 讨论 | Mate50/P60 也要"**拆机短接后直接解锁 bootloader 锁**" |

同一份指南的华为 Root 页也确认了链条：
> "一、解锁BL锁 —— **这是首要且必要的条件**"

之后才是刷 TWRP / 修补 `recovery_ramdisk` 刷 Magisk。

### 顺带确认的 Magisk 分区细节（将来若解锁成功可用）

| 系统 | 提取镜像 | 分区名 |
|---|---|---|
| EMUI 5 及以下 | BOOT.img | `boot` |
| EMUI 8 | RAMDISK.img | `ramdisk` |
| **EMUI 9 及以上（含鸿蒙）** | **RECOVERY_RAMDISK.img** | **`recovery_ramdisk`** |

⚠️ 官方系统**不要用 TWRP 双清/格式化 data**（华为把系统组件放在 data 里，会开不了机）。
